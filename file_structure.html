def split_sections(text: str) -> dict[str, str]
src/clean.py
split_sections(text: str) -> {"prepared_remarks": str, "qa_section": str, "split_found": bool}

Splits an earnings call transcript into Prepared Remarks (formal presentation by executives) and Q&A (spontaneous dialogue with equity analysts). Uses a regex cascade of 8 phrase patterns (e.g., "open the floor for questions", "operator: we are ready for Q&A", "question-and-answer session"). If no marker is matched, marks split_found=False and leaves Q&A empty.

Edge Cases Handled
Missing markers, multiple false positives in body text, case insensitivity, short calls (<500 words).
Data Output
Dictionary with cleaned sub-strings without operator boilerplate.
Implementation Blueprint 
import re

QA_PATTERNS = [
    r"(?:we will now|we'll now|we are now ready to)\s+(?:open|begin|take)\s+(?:the\s+)?(?:lines?|floor)?\s*(?:for\s+)?(?:questions?|q&a)",
    r"question[\s\-]and[\s\-]answer\s+session",
    r"(?:operator|coordinator):\s*(?:our first question|first question comes from|we will begin the q&a)",
    r"we are now opening the call for questions"
]

def split_sections(text: str) -> dict:
    for pat in QA_PATTERNS:
        match = re.search(pat, text, flags=re.IGNORECASE)
        if match:
            return {
                "prepared_remarks": text[:match.start()].strip(),
                "qa_section": text[match.end():].strip(),
                "split_found": True
            }
    return {"prepared_remarks": text.strip(), "qa_section": "", "split_found": False}
def remove_disclaimers(text: str) -> str
src/clean.py
remove_disclaimers(text: str) -> str

Strips boilerplate safe-harbour statements, Private Securities Litigation Reform Act disclosures, forward-looking statements disclaimers, and operator introductory instructions that skew vocabulary frequency toward synthetic legal risk.

Implementation Blueprint 
DISCLAIMER_PATTERNS = [
    r"safe\s+harbor\s+statement.*?(?=\n\n|\Z)",
    r"forward[\s\-]looking\s+statements?.*?(?:cautionary|reform\s+act).*?(?=\n\n|\Z)",
    r"at\s+this\s+time,\s+all\s+participants\s+are\s+in\s+a\s+listen[\s\-]only\s+mode.*?(?=\n\n|\Z)",
    r"please\s+note\s+(?:that\s+)?this\s+conference\s+is\s+being\s+recorded.*?(?=\n\n|\Z)"
]

def remove_disclaimers(text: str) -> str:
    cleaned = text
    for p in DISCLAIMER_PATTERNS:
        cleaned = re.sub(p, "", cleaned, flags=re.IGNORECASE | re.DOTALL)
    return re.sub(r"\n\s*\n+", "\n\n", cleaned).strip()

def load_lm_dictionary(dict_path: str) -> tuple[set, set]
src/sentiment_lm.py
load_lm_dictionary(dict_path: str) -> tuple[set[str], set[str]]

Reads the official Loughran-McDonald Master Dictionary (CSV/Excel). Extracts lowercased sets of positive words (e.g., achieve, profitable, robust, exceptional) and negative words (e.g., loss, impairment, default, adverse, downturn). Note that general words like "liability" or "tax" are not treated as negative under LM specifications.

Implementation Blueprint 
import pandas as pd

def load_lm_dictionary(dict_path: str) -> tuple[set, set]:
    df = pd.read_csv(dict_path)
    pos_words = set(df[df["Positive"] > 0]["Word"].str.lower())
    neg_words = set(df[df["Negative"] > 0]["Word"].str.lower())
    return pos_words, neg_words
def compute_lm_sentiment(text: str, pos_words: set, neg_words: set) -> dict
src/sentiment_lm.py
compute_lm_sentiment(text: str, pos_words: set, neg_words: set) -> {"lm_score": float, "pos_count": int, "neg_count": int, "total_words": int}

Tokenizes input text with word boundaries [a-zA-Z]+. Computes standard academic sentiment formula: $$\text{LM Score} = \frac{N_{\text{positive}} - N_{\text{negative}}}{N_{\text{total\_words}}}$$ Returns 0.0 if total words is 0. Computed separately for Full Text, Prepared Remarks, and Q&A.

def chunk_sentences(text: str, tokenizer, max_tokens: int = 510) -> list[str]
src/sentiment_finbert.py
chunk_sentences(text: str, tokenizer, max_tokens: int = 510) -> list[str]

Solves the transformer 512-token limit without truncating. First segments text into sentences using NLTK sent_tokenize. Then greedily packs complete sentences into chunks until adding the next sentence would exceed max_tokens (leaving 2 tokens for [CLS] and [SEP]). Never breaks a sentence midway.

Implementation Blueprint 
import nltk

def chunk_sentences(text: str, tokenizer, max_tokens: int = 510) -> list[str]:
    sentences = nltk.sent_tokenize(text)
    chunks, current_chunk, current_tokens = [], [], 0
    
    for sent in sentences:
        sent_tokens = len(tokenizer.tokenize(sent))
        if sent_tokens > max_tokens:
            # Handle exceptionally long run-on sentence
            words = sent.split()
            sent = " ".join(words[:int(max_tokens * 0.75)])
            sent_tokens = len(tokenizer.tokenize(sent))
            
        if current_tokens + sent_tokens <= max_tokens:
            current_chunk.append(sent)
            current_tokens += sent_tokens
        else:
            if current_chunk:
                chunks.append(" ".join(current_chunk))
            current_chunk = [sent]
            current_tokens = sent_tokens
            
    if current_chunk:
        chunks.append(" ".join(current_chunk))
    return chunks
def score_call_finbert(chunks: list[str], model, tokenizer, device: str) -> dict
src/sentiment_finbert.py
score_call_finbert(chunks: list[str], model, tokenizer, device: str, batch_size: int = 16) -> dict

Runs batch inference across chunks using PyTorch with torch.no_grad() and mixed precision (FP16/BF16) on GPU if available. Computes softmax probabilities over classes: Positive, Neutral, Negative. Aggregates to call level via: $$\text{finbert\_score} = \frac{1}{K}\sum_{k=1}^K [P(\text{positive})_k - P(\text{negative})_k]$$ $$\text{share\_negative} = \frac{1}{K}\sum_{k=1}^K \mathbb{I}\{\text{argmax}_c P(c)_k = \text{negative}\}$$

def get_event_day_zero(call_date: pd.Timestamp, call_timing: str, trading_calendar: list) -> pd.Timestamp
src/event_study.py
get_event_day_zero(call_date: pd.Timestamp, call_timing: str, trading_calendar: list) -> pd.Timestamp

Crucial timing alignment function preventing look-ahead and unobserved pricing errors:

  • Before Market Open (BMO): Price reaction occurs during trading hours of the same day → Day 0 is call_date (or next trading day if holiday/weekend).
  • After Market Close (AMC): Market was already closed → Day 0 is the immediate next trading day.

Implementation Blueprint 
def get_event_day_zero(call_date, call_timing: str, trading_days: list) -> pd.Timestamp:
    timing = str(call_timing).strip().upper()
    trading_set = set(trading_days)
    
    # If AMC or unspecified, reaction is next trading day
    if timing in ["AMC", "AFTER_CLOSE", "POST"]:
        future_days = [d for d in trading_days if d > call_date]
        return min(future_days)
    else:  # BMO or during trading hours
        valid_days = [d for d in trading_days if d >= call_date]
        return min(valid_days)

def compute_car(returns_df: pd.DataFrame, alpha: float, beta: float, event_day: pd.Timestamp, window: tuple[int, int]) -> float
src/event_study.py
compute_car(returns_df: pd.DataFrame, alpha: float, beta: float, event_day: pd.Timestamp, window: tuple[int, int] = (0, 1)) -> float

Computes Cumulative Abnormal Return (CAR) across event window $[t_1, t_2]$: $$AR_{it} = R_{it} - (\hat{\alpha}_i + \hat{\beta}_i R_{mt})$$ $$CAR_i[t_1, t_2] = \sum_{t=t_1}^{t_2} AR_{it}$$ Standard windows calculated: $[0, +1]$, $[0, +2]$, and pre-event leakage window $[-1, +1]$.

def run_controlled_ols(df: pd.DataFrame, y_col: str, sentiment_col: str) -> sm.regression.linear_model.RegressionResults
src/regression.py
run_controlled_ols(df: pd.DataFrame, y_col: str = "car_0_1", sentiment_col: str = "finbert_zscore", cluster_col: str = "ticker")

Estimates multi-factor cross-sectional regression with statsmodels: $$CAR_i = \gamma_0 + \gamma_1 \text{Sentiment}_i + \gamma_2 \text{EPS\_Surprise}_i + \gamma_3 \log(\text{MCap}_i) + \gamma_4 \text{PriorReturn}_i + \sum_s \delta_s \text{Sector}_{is} + \varepsilon_i$$ Applies heteroskedasticity and autocorrelation robust standard errors (HAC / Newey-West) clustered by firm or calendar date. Outputs coefficient, t-stat, p-value, and $R^2$.

Critical Methodological Pitfall Matrix
Essential Guardrails
Pitfall / Trap Impact on Results Mandatory Engineering Safeguard
Look-Ahead Bias Artificially inflated Sharpe & fake predictive power. Fix: Strict point-in-time consensus EPS. Day 0 market model calibrated on $[-250, -30]$ ending strictly before event.
AMC vs BMO Timing Measuring return on Day 0 for After-Close call captures pre-call price noise! Fix: AMC calls must trigger reaction measurement on $T+1$ trading day via get_event_day_zero().
512-Token Truncation Losing 85% of call content (10,000 words truncated to first 400). Fix: Sentence-boundary preserving chunking with aggregation over all chunks in src/sentiment_finbert.py.
EPS Confounding Sentiment is merely an echo of earnings surprise. Fix: Multivariate regression controlling for standardized actual vs consensus EPS surprise.
Transaction Cost Erasure Short holding period (1-2 days) results in 200%+ annualized turnover. Fix: Sensitivity testing at 5, 10, 20, 50 bps per leg. Net-of-cost Sharpe reporting.
Class Imbalance Mirage High accuracy achieved by simply predicting majority class (Positive). Fix: Enforce Macro F1 and per-class precision/recall on neutral class in reports/validation.md.
Survivorship Bias Testing only on firms in today's S&P 500 misses historical delistings & bankruptcies. Fix: Document index point-in-time composition limitations in report limitations section.
