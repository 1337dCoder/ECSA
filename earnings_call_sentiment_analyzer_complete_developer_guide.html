1. Knowledge Base & Theory

❖ NLP Foundations

FinBERT: Pre-trained specifically on financial data. Avoids misclassifying accounting truths (e.g., "liability") as negative sentiment.

The 512-Token Limit: Transformers cannot process full transcripts natively. Truncation loses the Q&A section entirely. Greedy sentence chunking is structurally required.

Loughran-McDonald (LM): The academic bag-of-words standard. Acts as the baseline to prove FinBERT actually adds alpha over simple word-counting.

❖ Finance & Econometrics

Event Study & Day 0: BMO (Before Market Open) prices react same day. AMC (After Market Close) prices react the next trading day. Misalignment causes Look-Ahead Bias.

Market Model & CAR: We isolate abnormal returns ($AR_{it}$) by subtracting the beta-adjusted market return over the [-250, -30] estimation window.

Newey-West HAC: Standard errors must be Heteroskedasticity and Autocorrelation Consistent to prevent inflated $t$-statistics in regressions.

1. split_sections(text: str) -> dict

Isolates rehearsed remarks from spontaneous Q&A using operator regex cues.

def split_sections(text):
    patterns = [r"we are now ready to open the floor", r"question-and-answer session"]
    for pat in patterns:
        match = re.search(pat, text, flags=re.IGNORECASE)
        if match: return {"prepared": text[:match.start()], "qa": text[match.end():]}
    return {"prepared": text, "qa": ""}

2. remove_disclaimers(text: str) -> str

Strips safe-harbor legalese that artificially skews NLP negative.

def remove_disclaimers(text):
    return re.sub(r"forward[\s\-]looking\s+statements?.*?(?=\n\n|\Z)", "", text, flags=re.IGNORECASE)

3. clean_dataset(raw_df: pd.DataFrame) -> pd.DataFrame

Executes full cleaning pipeline, drops duplicates, filters calls < 500 words.

def clean_dataset(df):
    df['text'] = df['text'].apply(remove_disclaimers)
    splits = df['text'].apply(split_sections)
    df['prepared'], df['qa'] = splits.apply(lambda x: x['prepared']), splits.apply(lambda x: x['qa'])
    return df[df['text'].str.split().str.len() > 500].drop_duplicates(['ticker', 'date'])

def load_lm_dictionary(path):
    df = pd.read_csv(path)
    pos = set(df[df["Positive"] > 0]["Word"].str.lower())
    neg = set(df[df["Negative"] > 0]["Word"].str.lower())

5. compute_lm_sentiment(text: str, pos: set, neg: set) -> dict

Computes normalized score: (pos - neg) / total_words.

def compute_lm_sentiment(text, pos_words, neg_words):
    words = re.findall(r'[a-zA-Z]+', text.lower())
    pos_count = sum(1 for w in words if w in pos_words)
    neg_count = sum(1 for w in words if w in neg_words)
    return {"lm_score": (pos_count - neg_count) / max(len(words), 1)}

Module: src/sentiment_finbert.py

6. chunk_sentences(text: str, tokenizer, max: int=510) -> list

Packs sentences greedily into 510 token limit without breaking context.

def chunk_sentences(text, tokenizer, max_tokens=510):
    sentences = nltk.sent_tokenize(text)
    chunks, curr_chunk, curr_len = [], [], 0
    for s in sentences:
        s_len = len(tokenizer.tokenize(s))
        if curr_len + s_len <= max_tokens:
            curr_chunk.append(s); curr_len += s_len
        else:
            chunks.append(" ".join(curr_chunk))
            curr_chunk, curr_len = [s], s_len
    if curr_chunk: chunks.append(" ".join(curr_chunk))
    return chunks

7. score_call_finbert(chunks: list, model, tokenizer) -> dict

Runs batched GPU inference and aggregates mean probabilities.

def score_call_finbert(chunks, model, tokenizer, device="cuda"):
    inputs = tokenizer(chunks, padding=True, truncation=True, return_tensors="pt").to(device)
    with torch.no_grad():
        probs = torch.nn.functional.softmax(model(**inputs).logits, dim=-1)
    net_score = (probs[:, 0] - probs[:, 1]).mean().item() # Pos - Neg
    return {"finbert_score": net_score, "share_neg": (probs.argmax(dim=-1) == 1).float().mean().item()}

8. get_event_day_zero(call_date, timing, calendar) -> date

Prevents look-ahead bias by shifting AMC calls to the next trading day.

def get_event_day_zero(call_date, timing, trading_days):
    if timing in ["AMC", "AFTER_CLOSE"]:
        return min([d for d in trading_days if d > call_date])
    return min([d for d in trading_days if d >= call_date])

9. estimate_market_model(stock_ret, market_ret) -> tuple

Fits pre-event OLS over [-250, -30] window.

def estimate_market_model(stock_returns, market_returns):
    X = sm.add_constant(market_returns)
    model = sm.OLS(stock_returns, X).fit()
    return model.params['const'], model.params.iloc[1] # Alpha, Beta

10. compute_car(returns_df, alpha, beta, t1, t2) -> float

Calculates Cumulative Abnormal Returns over [t1, t2] window.

def compute_car(returns_df, alpha, beta, t1, t2):
    # subset to [day_0 + t1, day_0 + t2]
    ar = returns_df['stock'] - (alpha + beta * returns_df['market'])
    return ar.sum()

    model = smf.ols('car_0_1 ~ finbert_z + eps_surp_z + log_mcap + C(sector)', data=df)

12. spearman_rank_test(df, sent_col, car_col) -> tuple

Non-parametric rank test, robust to price outliers.

def spearman_rank_test(df, sent_col, car_col):
    from scipy.stats import spearmanr
    return spearmanr(df[sent_col], df[car_col])

13. simulate_strategy(df, holding_days, cost_bps) -> float

Long top quintile (Q5), short bottom (Q1) minus friction.

def simulate_strategy(df, cost_bps=10):
    df['q'] = pd.qcut(df['finbert_z'], 5, labels=False)
    long_ret = df[df['q'] == 4]['car_0_1'].mean()
    short_ret = df[df['q'] == 0]['car_0_1'].mean()
    cost = (cost_bps / 10000) * 4 # Entry/exit for both legs
    return (long_ret - short_ret) - cost

14. compute_performance_metrics(returns_series) -> dict

Generates Sharpe, Volatility, and Drawdown stats.

def compute_performance_metrics(returns):
    ann_ret = returns.mean() * 252
    ann_vol = returns.std() * np.sqrt(252)
    sharpe = ann_ret / ann_vol if ann_vol > 0 else 0
    return {"annualized_return": ann_ret, "sharpe": sharpe}

  • Phase 4: Run FinBERT with 510-token chunks. Calculate (Pos-Neg) mean. Compute LM baseline score.
  • Phase 5: Hand-label 200 hold-out sentences. Generate Confusion Matrix. Prove FinBERT macro F1 beats LM.

Phases 6-9: Regressions & Trading Backtest

  • Phase 6: Standardize sentiment (z-score). Chart CAR distributions by sentiment quintiles.
  • Phase 7: Run HAC regressions: CAR ~ Sentiment + EPS_Surprise + log(MarketCap).
  • Phase 8: Build Long Q5 / Short Q1 portfolio simulation rule with strictly 0 look-ahead bias.
  • Phase 9: Apply strict out-of-sample freeze (tune on 2015-2020, test strictly on 2021+). Subtract 10bps friction.

Phases 10-12: Robustness & Finalization

  • Phase 10: Robustness testing. Winsorize 1% CAR outliers. Exclude 2020 crash months.
