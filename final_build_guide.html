Prerequisites

Before writing code, verify access to the following core datasets, models, and academic foundations:

  • Transcripts Dataset: Hugging Face kurry/sp500_earnings_transcripts (~33k S&P 500 transcripts).
  • Financial NLP Model: Hugging Face ProsusAI/finbert (BERT fine-tuned on financial text for Positive/Neutral/Negative classification).
  • Dictionary Baseline: Loughran-McDonald Master Dictionary (Required to prevent false negatives on accounting terminology).
  • Market Data API: yfinance for daily adjusted close prices and benchmark returns.
  • Econometrics Theory: Event Study Methodology (MacKinlay 1997) for CAR estimation, and Newey-West HAC robust standard errors.

Phase 1 & 2

Sourcing, Parsing & Cleaning Transcripts

src/clean.py

Isolates spontaneous Q&A from scripted management remarks and strips legal safe-harbor disclaimers that skew sentiment negative.

src/clean.py python 
import re
import pandas as pd

def split_sections(text: str) -> dict:
    """Isolates spontaneous Q&A from scripted management remarks."""
    patterns = [
        r"(?:we will now|we'll now)\s+(?:open|begin)\s+(?:the\s+)?(?:lines?|floor)?\s*(?:for\s+)?(?:questions?|q&a)",
        r"question[\s\-]and[\s\-]answer\s+session"
    ]
    
    for pat in patterns:
        match = re.search(pat, text, flags=re.IGNORECASE)
        if match:
            return {
                "prepared_remarks": text[:match.start()].strip(),
                "qa_section": text[match.end():].strip()
            }
    return {"prepared_remarks": text.strip(), "qa_section": ""}

def remove_disclaimers(text: str) -> str:
    """Removes legal safe-harbor statements that skew sentiment negatively."""
    clean_text = re.sub(r"forward[\s\-]looking\s+statements?.*?(?:cautionary|reform\s+act).*?(?=\n\n|\Z)", "", text, flags=re.IGNORECASE | re.DOTALL)
    return clean_text.strip()
Phase 3

Event Study & Abnormal Returns

src/event_study.py

Prevents look-ahead bias by correctly aligning trading day zero for After-Market-Close (AMC) versus Before-Market-Open (BMO) earnings announcements.

src/event_study.py python 
import pandas as pd

def get_event_day_zero(call_date: pd.Timestamp, call_timing: str, trading_days: list) -> pd.Timestamp:
    """Aligns the market reaction to the correct trading day."""
    if call_timing.upper() in ["AMC", "AFTER_CLOSE"]:
        future_days = [d for d in trading_days if d > call_date]
        return min(future_days)
    else:  # BMO (Before Market Open)
        valid_days = [d for d in trading_days if d >= call_date]
        return min(valid_days)

def compute_car(returns_df, alpha, beta, event_day):
    """Computes Cumulative Abnormal Return [0, +1]"""
    event_returns = returns_df.loc[event_day : event_day + pd.Timedelta(days=1)]
    ar = event_returns['stock'] - (alpha + beta * event_returns['market'])
    return ar.sum()
Phase 4

Sentiment Engine & FinBERT Chunking

src/sentiment_finbert.py

Bypasses the 512-token transformer limit by intelligently chunking transcript sentences into safe 510-token segments before inference.

src/sentiment_finbert.py python 
import nltk
import torch
from transformers import AutoTokenizer, AutoModelForSequenceClassification

tokenizer = AutoTokenizer.from_pretrained("ProsusAI/finbert")
model = AutoModelForSequenceClassification.from_pretrained("ProsusAI/finbert")

def chunk_sentences(text: str, max_tokens: int = 510) -> list:
    """Packs sentences into 510-token chunks to bypass BERT limits."""
    sentences = nltk.sent_tokenize(text)
    chunks, curr_chunk, curr_tokens = [], [], 0
    
    for sent in sentences:
        tokens = len(tokenizer.tokenize(sent))
        if curr_tokens + tokens <= max_tokens:
            curr_chunk.append(sent)
            curr_tokens += tokens
        else:
            chunks.append(" ".join(curr_chunk))
            curr_chunk, curr_tokens = [sent], tokens
            
    if curr_chunk: chunks.append(" ".join(curr_chunk))
    return chunks

def score_chunks(chunks: list) -> float:
    """Returns average (Prob(Positive) - Prob(Negative))"""
    inputs = tokenizer(chunks, padding=True, truncation=True, return_tensors="pt")
    with torch.no_grad():
        outputs = model(**inputs)
        probs = torch.nn.functional.softmax(outputs.logits, dim=-1)
    
    pos_score = probs[:, 0].mean().item()
    neg_score = probs[:, 1].mean().item()
    return pos_score - neg_score
Phase 6 & 7

Controlled Regression & Econometrics

src/regression.py

Isolates true sentiment alpha via multivariate OLS regression controlling for EPS surprise, market cap, and prior momentum with clustered standard errors.

src/regression.py python 
import statsmodels.formula.api as smf
import pandas as pd

def run_regression(df: pd.DataFrame):
    """Proves sentiment adds value beyond just beating EPS."""
    df['sentiment_z'] = (df['finbert_score'] - df['finbert_score'].mean()) / df['finbert_score'].std()
    
    formula = "car_0_1 ~ sentiment_z + eps_surprise + log_mcap + prior_return"
    
    model = smf.ols(formula, data=df).fit(cov_type='cluster', cov_kwds={'groups': df['ticker']})
    print(model.summary())
    return model
Phase 8

Trading Simulator & Portfolio Backtest

src/backtest.py

Simulates a market-neutral long Q5 / short Q1 hedge fund strategy factoring in realistic transaction costs and slippage in basis points.

src/backtest.py python 
import pandas as pd

def simulate_strategy(df: pd.DataFrame, cost_bps: float = 10.0):
    """Simulates a Long Q5 / Short Q1 portfolio with slippage."""
    df['quintile'] = df.groupby('call_date')['finbert_score'].transform(
        lambda x: pd.qcut(x, 5, labels=False, duplicates='drop')
    )
    
    longs = df[df['quintile'] == 4]['car_0_1'].mean()
    shorts = df[df['quintile'] == 0]['car_0_1'].mean()
    
    gross_return = longs - shorts
    net_return = gross_return - (4 * (cost_bps / 10000))
    
    return net_return
