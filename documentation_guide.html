1. Knowledge Base & Resources

NLP: Models & Constraints

FinBERT (ProsusAI): A BERT model fine-tuned specifically on financial data (Financial PhraseBank). It categorizes text into Positive, Neutral, or Negative. Standard BERT fails in finance because words like "liability" or "tax" are neutral facts in accounting, but negative in standard English.

The 512-Token Limit: Transformer models possess a hard quadratic memory limit. You cannot feed a 10,000-word earnings call directly into BERT. Standard truncation discards the end of the call (often where Q&A reveals the most truth). Chunking is the mandatory solution.

Loughran-McDonald (LM): The academic gold standard baseline (2011). A bag-of-words dictionary built from 10-K filings. It is transparent and fast, used here to prove that complex Transformers (FinBERT) actually capture nuance better than simple word counting.

Finance: Event Studies & Math

Event Study & Day 0: We isolate the market's reaction to the call. If a call happens After Market Close (AMC), the price reaction occurs the next trading day. Day 0 must be aligned perfectly, otherwise you test the model on random noise.

Market Model & CAR: Stock returns ($R_{it}$) are driven by the market ($R_{mt}$). We estimate normal behavior: $R_{it} = \alpha + \beta R_{mt}$ over a [-250, -30] window. The Cumulative Abnormal Return (CAR) is the sum of the residuals ($AR$) during the [0, +1] event window.

Econometrics (Newey-West): When regressing CAR on Sentiment, errors are often correlated across time or firms (heteroskedasticity). We use HAC (Heteroskedasticity and Autocorrelation Consistent) standard errors to ensure our $t$-statistics aren't falsely inflated.

A. src/clean.py: The Section Splitter

The Knowing: Prepared remarks are legally sanitized and rehearsed. Q&A is spontaneous. Literature proves Q&A holds the alpha. We use regex to split them based on standard operator phrasing.

def split_sections(text: str) -> dict:
    # We look for the pivot point where management stops reading and analysts start asking.
    qa_patterns = [r"we are now ready to open the floor for questions", r"question-and-answer session"]
    for pat in qa_patterns:
        match = re.search(pat, text, flags=re.IGNORECASE)
        if match:
            return {"prepared": text[:match.start()], "qa": text[match.end():]}
    return {"prepared": text, "qa": ""}

B. src/sentiment_finbert.py: The Context-Preserving Chunker

The Knowing: If we truncate at 512 tokens, we lose the end of the call. If we split blindly by character, we cut sentences in half, destroying transformer attention maps. We must tokenize by sentence first, then greedily pack them into 510-token chunks.

import nltk
def chunk_sentences(text: str, tokenizer, max_tokens: int = 510) -> list:
    sentences = nltk.sent_tokenize(text)
    chunks, current_chunk, current_tokens = [], [], 0
    
    for sent in sentences:
        sent_tokens = len(tokenizer.tokenize(sent))
        if current_tokens + sent_tokens <= max_tokens:
            current_chunk.append(sent)
            current_tokens += sent_tokens
        else:
            chunks.append(" ".join(current_chunk))
            current_chunk = [sent]
            current_tokens = sent_tokens
    
    if current_chunk: chunks.append(" ".join(current_chunk))
    return chunks

C. src/event_study.py: The Time Aligner

The Knowing: A fatal flaw in quant research is Look-Ahead Bias. If a call happens at 5:00 PM (After Market Close), trading on Day 0's close implies time travel. Day 0 must be programmatically forced to the next trading day.

def get_event_day_zero(call_date, call_timing: str, trading_days: list) -> pd.Timestamp:
    # If After Market Close (AMC), reaction cannot occur until tomorrow.
    if call_timing.upper() in ["AMC", "AFTER_CLOSE"]:
        future_days = [d for d in trading_days if d > call_date]
        return min(future_days)
    # BMO (Before Market Open) reacts today.
    return min([d for d in trading_days if d >= call_date])

Phase 4: FinBERT & LM Scoring

Initialize transformers pipeline with GPU support and chunk processing.

# Python: src/sentiment_finbert.py
import torch
from transformers import AutoTokenizer, AutoModelForSequenceClassification

device = "cuda" if torch.cuda.is_available() else "cpu"
tokenizer = AutoTokenizer.from_pretrained("ProsusAI/finbert")
model = AutoModelForSequenceClassification.from_pretrained("ProsusAI/finbert").to(device)

def score_text(text):
    chunks = chunk_sentences(text, tokenizer)
    inputs = tokenizer(chunks, padding=True, truncation=True, return_tensors="pt").to(device)
    with torch.no_grad():
        outputs = model(**inputs)
        probs = torch.nn.functional.softmax(outputs.logits, dim=-1)
    
    pos_prob = probs[:, 0].mean().item()
    neg_prob = probs[:, 1].mean().item()
    return pos_prob - neg_prob # Net sentiment score

# Standardize sentiment
df['sent_z'] = (df['finbert_score'] - df['finbert_score'].mean()) / df['finbert_score'].std()

# OLS Regression with Newey-West standard errors (cov_type='HAC')
model = smf.ols('CAR_0_1 ~ sent_z + eps_surprise + log_mcap', data=df).fit(
    cov_type='HAC', cov_kwds={'maxlags': 1}
)

Phases 8-9: Trading Backtest

Sort stocks into quintiles. Long Q5, Short Q1. Add transaction friction.

# Python: src/backtest.py
def backtest(df, cost_bps=10):
    df['quintile'] = pd.qcut(df['sent_z'], 5, labels=False)
    
    longs = df[df['quintile'] == 4]['CAR_0_1'].mean()
    shorts = df[df['quintile'] == 0]['CAR_0_1'].mean()
    
    # Return spread minus transaction costs (two legs, round trip)
    cost_decimal = cost_bps / 10000.0
    spread = (longs - shorts) - (4 * cost_decimal)
    
    return spread
