Earnings Call Sentiment Analyzer Build Guide

A comprehensive, step-by-step implementation manual to construct the pipeline from raw transcripts to trading backtest.

Essential Resources & Knowledge

Before writing code, ensure you have access to the following academic and technical resources to validate the pipeline:

  • Transcripts Dataset: Hugging Face kurry/sp500_earnings_transcripts (Approx 33k S&P 500 transcripts).
  • Financial NLP Model: Hugging Face ProsusAI/finbert (BERT fine-tuned on financial text for Positive/Neutral/Negative classification).
  • Dictionary Baseline: Loughran-McDonald Master Dictionary (Required to prevent false negatives on words like "liability" or "tax").
  • Market Data API: yfinance for daily adjusted close prices and SPY benchmark returns.
  • Econometrics Theory: Event Study Methodology (MacKinlay 1997) for CAR estimation, and Newey-West HAC robust standard errors for regressions.

Phase 1 & 2: Sourcing & Cleaning

Parsing Transcripts (src/clean.py)

import re
import pandas as pd

def split_sections(text: str) -> dict:
    """Isolates spontaneous Q&A from scripted management remarks."""
    patterns = [
        r"(?:we will now|we'll now)\s+(?:open|begin)\s+(?:the\s+)?(?:lines?|floor)?\s*(?:for\s+)?(?:questions?|q&a)",
        r"question[\s\-]and[\s\-]answer\s+session"
    ]
    
    for pat in patterns:
        match = re.search(pat, text, flags=re.IGNORECASE)
        if match:
            return {
                "prepared_remarks": text[:match.start()].strip(),
                "qa_section": text[match.end():].strip()
            }
    return {"prepared_remarks": text.strip(), "qa_section": ""}

def remove_disclaimers(text: str) -> str:
    """Removes legal safe-harbor statements that skew sentiment negatively."""
    clean_text = re.sub(r"forward[\s\-]looking\s+statements?.*?(?:cautionary|reform\s+act).*?(?=\n\n|\Z)", "", text, flags=re.IGNORECASE | re.DOTALL)
    return clean_text.strip()
What this does: Executives script their Prepared Remarks to sound overly optimistic, while the Q&A section reveals true dynamics. The split_sections function uses regex to find the exact moment the operator opens the line. remove_disclaimers strips out mandatory risk disclosures that trick sentiment models into flagging the call as "Negative" due to legal jargon.
Phase 3: Event Study

Abnormal Returns (src/event_study.py)

import pandas as pd

def get_event_day_zero(call_date: pd.Timestamp, call_timing: str, trading_days: list) -> pd.Timestamp:
    """Aligns the market reaction to the correct trading day."""
    if call_timing.upper() in ["AMC", "AFTER_CLOSE"]:
        future_days = [d for d in trading_days if d > call_date]
        return min(future_days)
    else:  # BMO (Before Market Open)
        valid_days = [d for d in trading_days if d >= call_date]
        return min(valid_days)

def compute_car(returns_df, alpha, beta, event_day):
    """Computes Cumulative Abnormal Return [0, +1]"""
    # AR = Stock_Return - (Alpha + Beta * Market_Return)
    event_returns = returns_df.loc[event_day : event_day + pd.Timedelta(days=1)]
    ar = event_returns['stock'] - (alpha + beta * event_returns['market'])
    return ar.sum()
What this does: Fixes the most common algorithmic trading bug: Look-Ahead Bias. If a company reports earnings After Market Close (AMC), the stock price cannot react until the next trading day. This code accurately aligns Day 0. It then calculates the CAR by subtracting the expected market movement (Beta * Market) from the actual stock movement.
Phase 4: Sentiment Engine

FinBERT Chunking (src/sentiment_finbert.py)

import nltk
import torch
from transformers import AutoTokenizer, AutoModelForSequenceClassification

tokenizer = AutoTokenizer.from_pretrained("ProsusAI/finbert")
model = AutoModelForSequenceClassification.from_pretrained("ProsusAI/finbert")

def chunk_sentences(text: str, max_tokens: int = 510) -> list:
    """Packs sentences into 510-token chunks to bypass BERT limits."""
    sentences = nltk.sent_tokenize(text)
    chunks, curr_chunk, curr_tokens = [], [], 0
    
    for sent in sentences:
        tokens = len(tokenizer.tokenize(sent))
        if curr_tokens + tokens <= max_tokens:
            curr_chunk.append(sent)
            curr_tokens += tokens
        else:
            chunks.append(" ".join(curr_chunk))
            curr_chunk, curr_tokens = [sent], tokens
            
    if curr_chunk: chunks.append(" ".join(curr_chunk))
    return chunks

def score_chunks(chunks: list) -> float:
    """Returns average (Prob(Positive) - Prob(Negative))"""
    inputs = tokenizer(chunks, padding=True, truncation=True, return_tensors="pt")
    with torch.no_grad():
        outputs = model(**inputs)
        probs = torch.nn.functional.softmax(outputs.logits, dim=-1)
    
    # FinBERT classes: 0=Positive, 1=Negative, 2=Neutral
    pos_score = probs[:, 0].mean().item()
    neg_score = probs[:, 1].mean().item()
    return pos_score - neg_score
What this does: Transformer models crash or truncate text longer than 512 tokens. An earnings call is ~8,000 words. This algorithm carefully segments the transcript into complete sentences, groups them into safe 510-token chunks, processes them in parallel through FinBERT, and averages the net positivity score.
Phase 6 & 7: Econometrics

Controlled Regression (src/regression.py)

import statsmodels.formula.api as smf

def run_regression(df: pd.DataFrame):
    """Proves sentiment adds value beyond just beating EPS."""
    # Standardize sentiment for interpretable coefficients
    df['sentiment_z'] = (df['finbert_score'] - df['finbert_score'].mean()) / df['finbert_score'].std()
    
    formula = "car_0_1 ~ sentiment_z + eps_surprise + log_mcap + prior_return"
    
    # Fit OLS with robust standard errors clustered by ticker
    model = smf.ols(formula, data=df).fit(cov_type='cluster', cov_kwds={'groups': df['ticker']})
    print(model.summary())
    return model
What this does: A naive model might think a positive transcript causes the stock to rise, when in reality, the company just reported a massive EPS beat. This multivariate OLS regression isolates the "Sentiment Alpha" by controlling for the EPS Surprise, Market Cap, and prior momentum, applying Newey-West standard errors to ensure statistical significance (t-stat > 2.0).
Phase 8: Trading Simulator

Portfolio Backtest (src/backtest.py)

def simulate_strategy(df: pd.DataFrame, cost_bps: float = 10.0):
    """Simulates a Long Q5 / Short Q1 portfolio with slippage."""
    # Rank by sentiment each quarter
    df['quintile'] = df.groupby('call_date')['finbert_score'].transform(
        lambda x: pd.qcut(x, 5, labels=False, duplicates='drop')
    )
    
    longs = df[df['quintile'] == 4]['car_0_1'].mean()
    shorts = df[df['quintile'] == 0]['car_0_1'].mean()
    
    gross_return = longs - shorts
    # Apply transaction costs (entry + exit for both legs = 4 * bps)
    net_return = gross_return - (4 * (cost_bps / 10000))
    
    return net_return
What this does: Transforms the academic signal into a market-neutral hedge fund strategy. It buys the top 20% most positive calls (Q5) and shorts the bottom 20% (Q1). Crucially, it subtracts basis points (bps) to simulate real-world slippage and brokerage fees, proving if the strategy survives live trading conditions.
Phase 11 & 12: Deployment

Interactive Dashboard (app.py)

import streamlit as st
from clean import split_sections
from sentiment_finbert import chunk_sentences, score_chunks

st.title("Earnings Call Analyzer")
transcript = st.text_area("Paste Transcript Here:")

if st.button("Analyze Sentiment"):
    sections = split_sections(transcript)
    
    st.subheader("Prepared Remarks Tone")
    st.progress(score_chunks(chunk_sentences(sections['prepared_remarks'])))
    
    st.subheader("Q&A Tone (Spontaneous)")
    st.progress(score_chunks(chunk_sentences(sections['qa_section'])))
What this does: Wraps the complex NLP pipeline into an intuitive Streamlit UI. Institutional investors or users can simply paste a raw transcript and instantly see the divergence between what management scripted (Prepared Remarks) and how they handled pressure from analysts (Q&A).
